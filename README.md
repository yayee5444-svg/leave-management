# 📋 ระบบบันทึกการลา (Leave Management)

ระบบบันทึกการลาแบบ HTML ที่เชื่อมต่อกับโฟลเดอร์ Google Drive

## ✨ ฟีเจอร์

- 📝 บันทึกการลา: ลาป่วย, ลากิจ, ลาพักร้อน, อื่นๆ
- 📅 เลือกวัน/เดือน/ปี (2026-2027)
- 📎 แนบเอกสารประกอบการลา
- 🗂️ ลิงก์โฟลเดอร์ Google Drive ตามวันที่เลือก
- 📊 สรุปสถิติการลา
- 🔍 ค้นหาและกรองรายการ
- 💾 บันทึกข้อมูลใน LocalStorage

## 📂 โครงสร้าง Google Drive

```
Template วันลา/
├── 2026/
│   ├── พ.ย./ (1-30)
│   └── ธ.ค./ (1-31)
└── 2027/
    ├── ม.ค./ (1-31)
    ├── ก.พ./ (1-28)
    ├── มี.ค./ (1-31)
    ├── เม.ย./ (1-30)
    ├── พ.ค./ (1-31)
    ├── มิ.ย./ (1-30)
    ├── ก.ค./ (1-31)
    ├── ส.ค./ (1-31)
    ├── ก.ย./ (1-30)
    ├── ต.ค./ (1-31)
    ├── พ.ย./ (1-30)
    └── ธ.ค./ (1-31)
```

## 🚀 วิธีใช้งาน

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม
